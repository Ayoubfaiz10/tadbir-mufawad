# تطبيق تسيير المفوض القضائي — Gestion Huissier

تطبيق ديسكتوب (Electron) لتسيير أعمال المفوضين القضائيين (huissiers de justice). واجهة ثنائية اللغة: **العربية (RTL)** و **الفرنسية (LTR)**، مع مظهر فاتح/داكن.

> ملاحظة: هذه **بنية أساسية (v0.1.0)**. الوظائف المتخصصة للتوليد التلقائي للوثائق القانونية (التبليغ، التنفيذ، المعاينة) ستضاف بعد دراسة متطلبات المهنة.

---

## التشغيل

```bash
npm install        # التثبيت (مرة واحدة)
npm start          # تشغيل التطبيق
```

بناء نسخة قابلة للتوزيع (Windows):

```bash
npm run dist
```

---

## هيكل المشروع

```
📦 تطبيق مفوض تلقائي
├── main.js                  # العملية الرئيسية: النافذة، القائمة، التخزين (IPC)
├── preload.js               # جسر آمن بين العملية الرئيسية والواجهة (contextBridge)
├── package.json
└── src/
    ├── index.html           # الواجهة (5 صفحات + نافذة منبثقة)
    ├── style.css            # نظام التصميم (متغيرات، RTL/LTR، فاتح/داكن)
    ├── app.js               # منطق الواجهة: اللغة، التنقل، CRUD، النماذج
    └── locales/
        ├── ar.json          # ترجمات العربية
        └── fr.json          # ترجمات الفرنسية
```

## التخزين

تُحفظ البيانات تلقائياً (JSON) في مجلد بيانات التطبيق:

- Windows: `C:\Users\<المستخدم>\AppData\Roaming\<اسم التطبيق>\data\store.json`

---

## إضافة وحدة جديدة (مثال: توليد الوثائق)

1. **الترجمات**: أضف مفاتيح جديدة في `src/locales/ar.json` و `src/locales/fr.json` تحت قسم `documents`.
2. **الواجهة**: أنشئ الصفحة في `src/index.html` ضمن `<main>`.
3. **المنطق**: أضف الدوال في `src/app.js` واربطها في `bindEvents()`.
4. **الطباعة/PDF**: يمكن استخدام `webContents.printToPDF` في `main.js` مع زر في الواجهة عبر IPC جديد.
